# For Faith — Mama ❤️

This is a personalized romantic website for Faith ("Mama"), made by Dobby.

## Files

- `index.html` — page content
- `style.css` — design and animations
- `script.js` — interactions
- `images/` — the five supplied photos

## Put it online with GitHub Pages

1. Create/sign in to GitHub.
2. Create a new **public** repository.
3. Upload all files and the `images` folder.
4. Go to **Settings → Pages**.
5. Under Build and deployment, select **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then Save.
7. GitHub will provide the `github.io` address.

The site uses only HTML/CSS/JavaScript, so no server is needed.
